# 参与 Oil Git

[English](../../CONTRIBUTING.md)

Oil Git 是读取真实 Git 仓库的只读桌面工具。贡献应帮助用户理解分支、提交与文件变化，查看行为不能修改被观察的仓库。

## 问题与建议

报告问题时，请提供系统与架构、应用版本或提交、复现步骤和预期行为。Git 边界问题最好附上可复现的独立临时仓库。分享日志或截图之前，请移除私有路径、邮箱与代码。

较大的功能改动建议先在 Issue 中说明用户需求。PR 保持聚焦，说明最终行为和实际运行过的检查。

## 开发

环境与检查命令见[开发说明](development.md)。[AGENTS.md](../../AGENTS.md) 记录只读访问、请求归属与渲染等工程约束。测试使用独立临时仓库。

生成的图标、主题 CSS、构建产物和本机验证记录不提交到源码。主题颜色在 `scripts/theme-palettes.json` 中维护，文件图标使用已有的 Material Icon Theme 资源。

## 语言与文档

应用支持英文和简体中文。添加用户界面文案时，同时更新 `src/i18n.tsx` 中的两种语言，包括提示、无障碍名称和错误说明。文件路径、提交信息、分支名称与作者姓名属于仓库数据，保留原文。

行为变化时同步更新中英文文档。默认入口为英文 README，中文版本位于 `README.zh-CN.md` 和 `docs/zh-CN/`。公开文档保留稳定的使用与贡献说明；本机验收流水和证据另存，不堆积在首页。

## 验证

在 PR 中关联提交、实际运行结果和未检查的范围。测试使用独立临时仓库，读取前后核对文件、暂存区、引用、配置和 LFS 对象库。不要使用个人仓库构造测试变化。

- **源码**：运行[开发说明](development.md#检查)中的相关命令。
- **安装包**：运行安装包里的程序和启动器，检查资源、CLI、退出码及仓库字节不变。通用 DMG 需要在 ARM64 和 Intel 上使用同一份安装包检查；Windows 检查 NSIS 安装后的程序。记录平台、架构与安装包 SHA-256。
- **原生窗口**：界面改动需要在目标平台操作真实窗口。检查打开与恢复项目、刷新与错误归属、文件范围、历史导航、换行与分栏、图片和行归属，以及语言、主题、复制反馈和减少动态效果。CLI 通过不能替代这些检查。

[Desktop CI](https://github.com/oil-oil/oil-git/actions/workflows/build.yml) 覆盖三平台源码和安装后 CLI 检查，不覆盖 WebView 渲染或原生交互。工作流配置、跳过的任务和本地交叉编译都不算平台通过。验收报告、截图和本机日志保存在仓库之外；公共文档描述稳定的行为与方法。
